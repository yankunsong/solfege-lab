# 简谱练习 · jianpu-trainer

一个帮助学乐理的小网站。纯静态页面（HTML + CSS + JS），无需构建。

## 功能一：简谱数字 ↔ 唱名

1. 选择要练习的音（例如 1 2 3 5）和每串的长度范围（例如 2–3）。
2. 网站随机生成一串数字，例如 `12`、`35`、`135`。
3. 自己先读出唱名，然后按 **空格** 显示答案（do re mi fa sol la si），可选同时播放音高。
4. 再按 **空格** 进入下一串。手机上点数字区域即可。

设置会保存在浏览器里。

## 本地运行

直接用浏览器打开 `index.html`，或：

```bash
npx serve .
```
